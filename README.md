# 云乘见

大连软件园接驳区的响应型接驳公交演示系统：像网约车一样呼叫，按公交的价格付费，并与地铁无缝衔接。

乘客端覆盖选点、呼叫、派单、等待、验票乘车、跨区换乘、支付、发票与在线客服的完整流程；另含一个仅本地使用的运营后台，用于维护客服知识库。

## 功能

- **呼叫接驳**：选起终点后按一口价派单，沿途可接送同向乘客；支持改站、提前下车与取消
- **跨区规划**：接驳 + 地铁 + 接驳一程规划，按真实道路里程与高德换乘数据计算
- **真实站台**：公交站按路侧拆分、地铁站按出入口拆分，按车辆行驶方向判断停靠侧
- **在线客服**：基于本地知识库的检索增强问答，流式输出，可关联订单解释费用与状态
- **运营后台**：知识库条目增删改，保存即刻对客服生效（`/ops`）

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发模式，默认 5173
```

生产模式由内置服务同时托管前端、运营后台与客服 API：

```bash
node server/index.mjs
```

打开 `http://127.0.0.1:5173/`。Windows 用户也可直接双击 `启动云乘见.bat`。

客服的 AI 回答需要智谱 GLM API Key。复制 `.env.example` 为 `server/config.local.json` 并填入 `apiKey`，或设置环境变量 `GLM_API_KEY`。未配置时客服仅给出规则库原文兜底，其余功能不受影响。
